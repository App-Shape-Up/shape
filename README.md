# Shape

App pessoal de saúde (água, e em breve treinos, dieta, suplementação e hábitos).

- App instalável (PWA) em HTML/CSS/JS puro, publicado pelo GitHub Pages a partir da branch `gh-pages`.
- Dados no Supabase, com login por e-mail e senha. Cada pessoa só vê os próprios dados (Row Level Security).
- Estrutura do banco: `supabase/schema.sql`.
- `config.js` sem valores = modo demonstração (dados só no navegador).
